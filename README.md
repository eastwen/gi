# 指标亮灯全景图 Demo

按 Figma 设计实现的交互式指标驾驶舱，包含完整顶部导航、左侧菜单、筛选、部门聚焦和指标悬浮提示。

## 运行

```bash
python3 -m http.server 5173
```

打开 <http://localhost:5173>。

也可以直接用浏览器打开 `index.html`。

## 交互

- 点击环形图中的部门扇区：聚焦该部门，其他扇区淡出。
- 每个指标柱内部按半径方向堆叠 9 个月，由内向外对应 1–9 月。
- 悬停月份或季度堆叠块：显示整段外凸效果，并查看亮灯状态和统计周期。
- 悬停具体指标：查看部门、指标名称、状态和数据层级。
- 点击“全部”：按增长、关注、回落、持平状态筛选。
- 点击右侧收起按钮：折叠左侧菜单。
- 按 `Esc`：退出当前聚焦或关闭筛选菜单。
